A Node 22 program that writes two lines to `/output/entry.txt`: a warning to its past self about one specific moment — a thin envelope from RISD, opened over the kitchen sink in April and never read past the first line — and one sentence on why it mattered: the scholarship inside expired, and a decade was spent blaming a school that had already said yes.

## Run it

```sh
node main.ts
```

This writes `/output/entry.txt` (two lines, 1–280 characters). Running it twice produces byte-identical output.
